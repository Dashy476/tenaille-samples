# Public and paid

Tenaille's public sample is enough for a lab hour. Paid material is a list of future ideas, not a second corpus hiding in this tree.

## Public, in this folder

- The Tenaille CLI (`demo`, `lookup`, `recon`, `assess`)
- Two synthetic inventories and two CVE fixtures
- HARBNGR's starter pack: twelve non-destructive checks (`packs/public-starter`)
- CVINFERNO and CVBASTION briefs generated from those fixtures
- Confirmation ceilings, with tests that block an "exploited" claim at `version_match`
- The MCP description stub

## Not public because it is not here

`packs/paid-reserved/README.md` says the paid pack is not in this folder. The ideas listed there are:

- Larger check packs
- Report themes
- A local-LLM narrative backend
- Dual-brief PDF export

No 13,000-check corpus is included or described as if it shipped.
